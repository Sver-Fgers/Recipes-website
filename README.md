# Recipes Website Project  
A simple HTML & CSS project 

## 🚀 Project Overview  
This project is a multi-page food recipe static website using only HTML and CSS. It demonstrates basic HTML structure, CSS styling, and responsive layout.

## 🎯 Why This Project  
- To practise HTML fundamentals (semantic tags, lists, images)  
- To learn CSS styling & layout (flexbox, grid, responsive design)  
- To build a complete small‐scale web project from scratch  
- To use it as a base for further enhancements (e.g., JavaScript interactivity, backend)  

## 🧩 Features (to implement)  
- Home page with a hero section and featured recipes  
- Recipes listing page showing multiple recipes  
- Individual recipe detail pages (ingredients + steps + images)  
- Responsive design: mobile, tablet, desktop  
- Navigation menu, footer with site info  
- Clean, semantic HTML markup and well‐structured CSS  

## 🛠️ Technologies & Tools  
- HTML5  
- CSS3 (including responsive techniques)  
- *Optional future*: JavaScript for interactivity
